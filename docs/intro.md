# Getting started

Infinite Ocean is an infinite, animated sea for Roblox. Pick the guide that fits you and it walks you through the rest.

<div className="ocean-paths">
  <Link className="ocean-path" to="/docs/no-scripting">
    <h3>No Scripting Guide</h3>
    <p>Install the Studio plugin and let the Quick Start build your sea: physics, look and addons in four pages, nothing typed.</p>
    <span className="ocean-path-cta">Start here →</span>
  </Link>
  <Link className="ocean-path" to="/docs/advanced">
    <h3>Advanced Guide</h3>
    <p>Install the plugin (recommended) or the open-source module on its own, then drive settings, weather, zones, water queries and events from code.</p>
    <span className="ocean-path-cta">For scripters →</span>
  </Link>
</div>

The No Scripting Guide needs the [**Infinite Ocean plugin**](https://create.roblox.com/store/asset/76752250508724/Infinite-Ocean). The Advanced Guide works with the module alone, but the plugin is strongly recommended: it is the only way to get the addons (buoyancy, swimming, drowning, splashes, weather effects, zones, DevTools).
